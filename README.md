# Rock-Paper-Scissors

A simple Rock-Paper-Scissors game built with HTML, CSS, and JavaScript.

## Live Demo

[Play the game](https://karimian-a.github.io/Rock-Paper-Scissors-Game/)

## Features

* Choose Rock, Paper, or Scissors
* Display the player's choice
* Display the computer's choice
* Show win, lose, or draw status
* Live player and computer scores
* Simple and interactive UI

## Technologies

* HTML5
* CSS3
* JavaScript

## Purpose

This project was built as a JavaScript practice project to work with DOM manipulation, events, functions, conditional logic, and `dataset`.
